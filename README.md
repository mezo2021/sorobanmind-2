### 3.3 بيانات الطفل

7 حقول أساسية:

| # | الحقل | مثال |
|---|---|---|
| 1 | `id` | child-001 |

| 4 | `code` | كود المعهد (اختياري) |
| 5 | `companion` | شام / ريان / جود / بانة |
| 6 | `createdAt` | تاريخ التسجيل |
| 7 | `category` | kids / teens |

**إعدادات لكل طفل:**
- اللغة (ar / en)
- نمط الأرقام (عربي ١٢٣ / لاتيني 123)
- الصوت (مفعّل/مكتوم)
- الاهتزاز (مفعّل/مكتوم)

**قفل الاسم:** يُقفل بعد أول شهادة (لا يمكن تغييره).

### 3.4 الصوت

| القرار | التفصيل |
|---|---|
| **قسم الصغار** | MP3 — صوت "نور" السورية (22 ملف) |

### 3.5 التقييم

| القرار | التفصيل |
|---|---|
| **"جرّب"** | مرة واحدة — خطأ → يظهر الجواب → يتابع (بلا تقييم) |
| **النجاح** | نهائي — لا إعادة امتحان |
| **الرسوب** | يمكن الإعادة بعد 24 ساعة |
| **تاريخ الشهادة** | تاريخ النجاح الفعلي (لا تاريخ الفتح) |
| **الشارة** | أعلى شارة فقط لكل مهارة (لا تراكم) |
| **منح الشارة** | في الامتحانات فقط (10 أسئلة/مهارة) |
| **زر التحقق** | تعليمي: بعد كل حركة · امتحان: بعد السؤال |

**أنواع الشارات:**

| الشارة | الشرط |
|---|---|
| 🥉 برونزي | زمن ≤ 40% من القياسي |
| 🥈 فضي | 5 أرقام قياسية متتالية |
| 🥇 ذهبي | 7 أرقام قياسية متتالية |

## 5️⃣ عقد المعرّفات

### الصيغة الموحّدة

```

{SOURCE}-L{N}-S{N}-{SEQ}

SOURCE: V2 | RAW | EX1 | EX2
N: بلا صفر (L0, L1... L7)
SEQ: 3 أرقام (001)

```

### أمثلة

| المصدر | ID |
|---|---|
| bank-v2 | `V2-L1-S5-025` |
| bank-raw | `RAW-L1-S5-021` |
| امتحان 1 | `EX1-L1-S5-001` |
| امتحان 2 | `EX2-L4-S16-012` |

### خريطة الربط (raw ↔ S ↔ L)

| raw | S | L |
|---|---|---|
| S1 | S3 | L1 |
| S2 | S5 | L1 |
| S3 | S7 | L1 |
| S4 | S9 | L1 |
| S5 | S10-S12 | L2 |
| S6 | S13-S15 | L3 |
| S7 | S16 (سالبة — محذوفة من الامتحانات) | L4 |
| S8 | S18 | L6 |
| S9 | S19 | L7 |
| S10 | S20 | L7 |
| S11-S17 | S16-S17 (متقدم) | L4-L5 |

**⚠️ ملاحظة:** ترقيم raw ≠ ترقيم S — يجب توخي الحذر عند الدمج.

### التصنيفات الإضافية (مقترح للتثبيت)

```

cognitiveLoad: low | medium | high
pattern: direct | complement | chain | reverse
learningStage: intro | practice | mastery | remediation
anzanMode: visual | flash | audio | imagination | reverse
errorType: conceptual | procedural | execution | timing

```

**أمثلة:**
- `3 + 1` → low · direct
- `3 + 4` → medium · complement
- `6 + 6` → high · chain

## 🔟 مبادئ العمل

### قواعد صارمة

1. **لا كود قبل وثيقة** — كل قرار يُوثَّق أولاً
2. **لا حكم على مجمّد** — مستقر وجاهز للتطوير
3. **لا إعادة بناء** — نكمل، لا نُعيد
4. **بنك raw = المرجع** — المنهج الياباني الأصلي
5. **دروسنا + raw = التميّز** — نجمع الأفضل من الاثنين
6. **قرار واحد لكل بند** — لا تعديل بعد الاتفاق
