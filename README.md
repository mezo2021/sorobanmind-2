### 🧒 الأبطال الصغار (5-12 سنة)

## 🚀 تشغيل المشروع محليًا

```bash
# 1. استنساخ المستودع
git clone https://github.com/mezo2021/sorobanmind-2.git

# 2. الدخول للمجلد
cd sorobanmind-2

# 3. تثبيت المكتبات
npm install

# 4. تشغيل بيئة التطوير
npm run dev

# 5. البناء للإنتاج
npm run build
```

ثم افتح: http://localhost:5173
