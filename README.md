## 👥 الفئتان العمريتان

### 🧒 الأبطال الصغار (5-12 سنة)
- **المستويات:** L0 → L3
- **المحتوى:** التأسيس · الأرقام · الجمع · الطرح · الضرب · القسمة
- **الأسلوب:** قصص · ألوان · أصوات · رفقاء

### 🧑 الأبطال الكبار (13+ سنة)
- **المستويات:** L4 → L7
- **المحتوى:** سلاسل متقدمة · ضرب وقسمة متقدم · عشري · جذور
- **الأسلوب:** منهج رسمي جدّي · تركيز على الإتقان

> **ملاحظة:** العمر مذكور في وصف التطبيق فقط — **لا يُذكر في نصوص الدروس** (قرار جلسة 14).

## 🎬 درس المقدمة (جديد — جلسة 14)

**7 صفحات · كل صفحة بصورة SVG متحركة:**

| # | العنوان | الصورة المتحركة |
|:-:|---|---|
| p1 | 🧮 السوروبان | سوروبان يطفو + يد تلوّح + «مرحباً يا بطل» |
| p2 | 📜 قصة السوروبان | رحلة الحصى → اليابان → السوروبان |
| p3 | 🔍 تعرّف على السوروبان | إطار · عارضة · أعمدة · خرزة علوية · سفلية |
| p4 | 🔑 القاعدة الذهبية | ملامسة العارضة · 0 → 5 → 1 |
| p5 | 🖐️ حرّك الخرزات | سوروبان تفاعلي 2D5 |
| p6 | 🌟 لماذا نتعلم السوروبان؟ | 6 بطاقات فوائد متتابعة |
| p7 | 🎯 هل أنت مستعد؟ | صاروخ + كأس + احتفال |

**بالإضافة إلى:**
- 🎯 قواعد الأصابع مطابقة لمنهج Kojima (الإبهام · السبابة · التقريص).
- 🖼️ إصلاح مسار الصور (`import.meta.env.BASE_URL`) — يعمل على GitHub Pages.

- **بنك SRB الموحّد** — 275 سؤالًا مصنّفًا بدقة.

## 🚀 تشغيل المشروع محليًا

