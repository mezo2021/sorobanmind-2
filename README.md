🎯 1. الرؤية

SorobanMind = تطبيق تعليمي عربي تفاعلي لتعلّم السوروبان الياباني.

الفكرة في سطر: تعليم السوروبان الياباني (منهج تاكاشي كوجيما) بالعربية — للأطفال والكبار — بدون إنترنت، بدون إعلانات، بخصوصية كاملة.

الأهداف:

1. منهج ياباني أصيل (Takashi Kojima + Japan Soroban Association)
2. تعليم تكيفي — كل طالب يحصل على أسئلة مخصّصة
3. فئتان عمريتان:
   · 🧒 قسم 1 (5–12): L0 → L3 + إثراء
   · 🧑 قسم 2 (13+): L4 → L7 + إثراء

الوعد للمستخدم:

· ✅ تطبيق عربي بتجربة تفاعلية
· ✅ منهج ياباني أصيل (كوجيما)
· ✅ بدون إعلانات — للأبد
· ✅ بدون إنترنت — يعمل offline
· ✅ خصوصية كاملة — البيانات على الجهاز

الميزة التنافسية:

محرك تكيفي حقيقي يفهم مهارات الطفل، يحدد نقاط ضعفه، ويولّد له أسئلة علاجية تلقائياً، مع مساري تمرّن وأنزان لكل درس.

💎 5. بنك الأسئلة SRB (البنك الوحيد المستقبلي)

بنية سؤال SRB:

```json
{
  "id": "SRB-L0-S01-B001",
  "original_bank_id": null,
  "original_bank_section": "NEW-GAPFILL",
  "curriculum_level": "L0",
  "curriculum_section": "01",
  "curriculum_section_name": "تمثيل الأرقام 0-9",
  "stage": "basic",
  "in_curriculum": true,
  "classification_note": "شرح مختصر لمصدر السؤال",
  "question": "مثّل العدد 0 على المعداد",
  "result": "0",
  "solution": "لا نحرك أي خرزة...",
  "note": null,
  "time_text": null,
  "target_time_ms": [1500, 2500],
  "digit_count_max": 1,
  "operand_count": 1,
  "difficulty_score": 1.35,
  "mastery_threshold": 0.85,
  "prerequisite_id": null,
  "next_if_success": "SRB-L0-S01-B002",
  "next_if_fail": "SRB-L0-S01-B001"
}
```

نظام ID:

الصيغة: SRB-L{مستوى}-S{قسم}-{B/A}{تسلسل}

الجزء المعنى
SRB بادئة بنك السوروبان
L0..L7 المستوى
S01..S20 القسم (بخانتين)
B / A أساسي (basic) / متقدم (advanced)
001..N التسلسل (3 أرقام)

📏 القواعد الصارمة:

1. digit_count_max = عدد خانات result (لا المضروب)
2. operand_count = عدد الأرقام في السؤال (وليس الجواب)
3. difficulty_score يتصاعد بانتظام (لا قفزات عشوائية)
4. solution نظيف — بلا مسودات ولا "تصحيح:" ولا "لكن الأبسط"
5. next_if_fail يرجع 3 خطوات داخل نفس القسم (معظم الحالات)
6. mastery_threshold = 0.85 للأساسي · 0.8 للمتقدم
7. stage = basic (L0-L3) · advanced (L4-L7)
8. target_time_ms = [min, max] حيث max = min × 1.5

🔍 نقاط المراجعة السبع (لكل مستوى جديد):

1. صحة البيانات — لا digit_count_max خاطئ
2. تسلسل الـ ID — B001 → B002 بلا فراغات
3. الشجرة — prerequisite / next_if_success / next_if_fail
4. الرياضيات — الجواب والشرح صحيحان
5. التغطية — كل قسم ≥ 15 سؤالاً
6. التوافق — الحقول المطلوبة للمحركات موجودة
7. السلامة النصية — لا مسودات، لا "تصحيح:"

· وضعان: Flash + عادي

· عدّاد تصاعدي + توهج 70% · زر إنهاء · 5 أسئلة
· ✅ AdaptiveFeedback · ✅ نمط الأرقام

🎯 10. نظام تتبّع الضعف

```typescript
interface WeakSkillRecord {
  skillId: string;
  attempts: number;
  correct: number;
  wrong: number;
  avgTimeMs: number;
  lastAttempt: number;
  weaknessScore: number;  // 0-100
}
```

القاعدة:

```
الضعف يُحسَب:
  - (1 - accuracy) × 60
  - + 20 إذا accuracy < 50%
  - + 20 إذا avgTimeMs > 15000

عتبة "ضعيف" = 50
نسبة الأسئلة العلاجية = 70%
```

التطبيق:

· recordWeaknessAttempt(skillId, correct, timeMs) — في كل إجابة
· getPracticeQuestions(num) — 70% للضعيف + 30% للعادي
