## 🎯 بنية كل مستوى

```text
📖 تعلّم (شاهد + جرّب)
    ↓
✏️ تمرّن (≥ 70%)
    ↓
🧠 أنزان بصري عادي (≥ 70%)
⚡ Flash Anzan (≥ 70%)
    ↓
🎧 أنزان سمعي (≥ 70%)
    ↓
🎓 اختبار المستوى (≥ 80%)
    ↓
📊 النتيجة التراكمية
    ↓
🏅 الشهادة
    ↓
📖 المستوى التالي
```

🧮 العلامة التراكمية

```text
النتيجة النهائية =
    70% × اختبار المستوى
  + 10% × التمرّن
  +  5% × أنزان بصري عادي
  +  5% × Flash Anzan
  + 10% × أنزان سمعي
  = 100%
```

⬅️ الأنزان البصري = متوسط حسابي (عادي + Flash) ÷ 2.

---

📐 قواعد العشرية

```text
1. إذا الناتج صحيح (result % 1 === 0) → يُعرض كما هو
2. إذا الناتج عشري → يُعرض برقمين بعد الفاصلة دائمًا (3.8 → 3.80)
3. الإدخال بدون فاصلة (3.80 → 380 · 0.48 → 48)
4. الأعمدة: صحيح = خانات الناتج · عشري = خانات الجزء الصحيح + 2
5. المقارنة: Math.round(result × 100) للعشري · result للصحيح
6. القسمة: بدون باقٍ فقط
```

✅ مطبقة في:

· CategoryExamScreen (CE1 · CE2)
· PlacementTestScreen (PT)
· PracticeScreen · AnzanScreen · AudioAnzanScreen
· Bank B (L6) — تنبيه "مثله N على المعداد" في حقل question
