## 🧠 هندسة التعليم التكيفي وانتقال البنوك

SorobanMind v2 يستخدم حاليًا **مرحلة انتقال هندسية مقصودة** بين نظام الأسئلة القديم والنظام الموحد الجديد SRB.

### 🎯 الحقيقة الجوهرية

المشروع **مكتمل ~90%** · عمره 6 أشهر · **يعمل ويستخدمه أطفال**.

**التشخيص الجذري:**
- تم عزل البنوك القديمة تمهيدًا للحذف (قرار سليم).
- جلسات لاحقة ربطت الشارات والأنزان بمصادر قديمة (لأن الأساس الجديد لم يكتمل).
- النتيجة: بعض الشارات تعمل · بعضها لا · بعضها مزدوج · بعض المفاتيح يتيمة.

**⚠️ ليست فوضى عشوائية — بل أثر خطة عزل نصف مُنفّذة.**

## 🎯 بنية كل مستوى

```text
📖 تعلّم (شاهد + جرّب)
    ↓
✏️ تمرّن (≥ 70%)
    ↓
🧠 أنزان بصري عادي (≥ 70%)
⚡ Flash Anzan (≥ 70%)
    ↓
🎧 أنزان سمعي (≥ 70%)
    ↓
🎓 اختبار المستوى (≥ 80%)
    ↓
📊 النتيجة التراكمية
    ↓
🏅 الشهادة
    ↓
📖 المستوى التالي
```

🧮 العلامة التراكمية

```text
النتيجة النهائية =
    70% × اختبار المستوى
  + 10% × التمرّن
  +  5% × أنزان بصري عادي
  +  5% × Flash Anzan
  + 10% × أنزان سمعي
  = 100%
```

⬅️ الأنزان البصري = متوسط حسابي (عادي + Flash) ÷ 2.

📐 قواعد العشرية

# القاعدة
1 إذا الناتج صحيح (result % 1 === 0) → يُعرض كما هو
2 إذا الناتج عشري → يُعرض برقمين بعد الفاصلة دائمًا (3.8 → 3.80)
3 الإدخال بدون فاصلة (3.80 → 380 · 0.48 → 48)
4 الأعمدة: صحيح = خانات الناتج · عشري = خانات الجزء الصحيح + 2
5 المقارنة: Math.round(result × 100) للعشري · result للصحيح
6 القسمة: بدون باقٍ فقط

🧠 الخطوة المفقودة — Attempt Record

كل محاولة للطالب يجب أن تُنتج سجلًا موحدًا:

```json
{
  "attemptId": "A-000184",
  "timestamp": 1760000000000,
  "level": "L1",
  "section": "S03",
  "skill": "S03-m2",
  "questionId": "L1-S03-m2-017",
  "phase": "P",
  "correct": false,
  "timeMs": 6200
}
```

الحلقة:

```text
Attempt Record → masteryTracker → adaptiveEngine → السؤال التالي
```

⬅️ recordAttempt() موجود في progressStore — لكن غير مستدعى.

⬅️ تفعيله = 3 أسطر في كل شاشة.

⬅️ هذه الحلقة المفقودة بين التمرين والمحرك التكيفي.
