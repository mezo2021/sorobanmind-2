## 🎯 1. الرؤية

**SorobanMind** = تطبيق تعليمي عربي تفاعلي لتعلّم السوروبان الياباني.

### الأهداف:
1. **منهج ياباني أصيل** (Takashi Kojima)
2. **تعليم تكيفي** — كل طالب يحصل على أسئلة مخصّصة
3. **فئتان عمرية:**
   - 🧒 **قسم 1** (5–12 سنة): L0 → L3 + الإثراء
   - 🧑 **قسم 2** (13+ سنة): L4 → L7 + الإثراء

### الميزة التنافسية:
> **محرك تكيفي حقيقي** يفهم مهارات الطفل، يحدد نقاط ضعفه، ويولّد له أسئلة علاجية تلقائياً، مع مساري تمرّن وأنزان لكل درس.

## 🧠 2. محرك التعليم التكيفي (Adaptive Engine)

### 📊 الفكرة:

```

الطفل يجيب سؤالاً
↓
bank.ts يعرف:

· skillId (المهارة)
· ruleId (القاعدة)
· movement (نوع الحركة)
· expectedTimeMs (الزمن المتوقع)
  ↓
  masteryTracker يقيس:
· هل الإجابة صحيحة؟
· كم استغرق؟
· هل هي متتالية؟
  ↓
  adaptiveEngine يقرر:
· 70% من مهارات ضعيفة
· 30% من مهارات جديدة
· صعوبة تتصاعد تلقائياً

```

### المكونات:

| # | الملف | الوظيفة | الحالة |
|---|-------|---------|--------|
| 1 | `engine/masteryTracker.ts` | يتتبع إتقان كل مهارة | ✅ |
| 2 | `engine/problemGenerator.ts` | يختار ويولّد الأسئلة | ✅ |
| 3 | `engine/adaptiveEngine.ts` | يتخذ القرارات التعليمية | ✅ |
| 4 | `data/bank.ts` | بنك الأسئلة (بيانات فقط) | ✅ |
| 5 | `engine/anzanEngine.ts` | محرك الأنزان (بصري + سمعي) | ⏳ قادم |

## 🔒 7. منطق القفل المتسلسل

### 🎯 القاعدة:

```

1. دخول التطبيق (طالب جديد):
   └── Placement Test (48 ساعة بين المحاولات)
   • نجاح 80% → يبدأ من L4 (قسم 2)
   • نجاح 60% → يبدأ من L0 (قسم 1)
   • فشل → ينتظر 48 ساعة
2. داخل القسم:
   📖 L(N) → يُفتح بعد إنهاء L(N-1) كاملاً
3. داخل المستوى:
   ✏️ تمرّن (N) → يُفتح بعد إنهاء درس L(N)
   🧠 أنزان (N) بصري → يُفتح بعد نجاح تمرّن (N)
   🧠 أنزان (N) سمعي → يُفتح بعد نجاح بصري (N)
4. المستوى التالي:
   📖 L(N+1) → يُفتح بعد نجاح:
   • تمرّن (N)
   • أنزان (N) بصري
   • أنزان (N) سمعي
5. امتحان القسم:
   🏆 يُفتح بعد إتمام كل المستويات + المسارات
   • قسم 1: 80% → ينتقل لقسم 2 (L4)
   • قسم 2: شهادة
6. الإثراء:
   ✅ مفتوح دائماً

```

### 🎯 عتبات النجاح:

| العنصر | العتبة |
|--------|--------|
| تمرّن | **75%** |
| أنزان (بصري) | **75%** |
| أنزان (سمعي) | **75%** |
| Placement Test (للانتقال) | **80%** |
| امتحان القسم | **80%** |
