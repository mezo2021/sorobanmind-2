🎯 1. الرؤية

SorobanMind تطبيق تعليمي عربي تفاعلي لتعلّم السوروبان الياباني.

الفكرة في سطر واحد: تعليم السوروبان الياباني (منهج تاكاشي كوجيما) بالعربية — للأطفال والكبار — بدون إنترنت، وبدون إعلانات، وبخصوصية كاملة.

الأهداف

1. منهج ياباني أصيل (Takashi Kojima + Japan Soroban Association).
2. تعليم تكيفي — كل طالب يحصل على أسئلة مخصّصة له.
3. فئتان عمريتان:
   · 🧒 القسم الأول (5–12 سنة): من L0 إلى L3 + الإثراء.
   · 🧑 القسم الثاني (13 سنة فأكثر): من L4 إلى L7 + الإثراء.

الوعد للمستخدم

· ✅ تطبيق عربي بتجربة تفاعلية.
· ✅ منهج ياباني أصيل (كوجيما).
· ✅ بدون إعلانات — للأبد.
· ✅ بدون إنترنت — يعمل دون اتصال.
· ✅ خصوصية كاملة — البيانات محفوظة على جهاز المستخدم.

الميزة التنافسية

محرك تكيفي حقيقي يفهم مهارات الطفل، ويحدد نقاط ضعفه، ويولّد له أسئلة علاجية تلقائياً، مع مساري تمرّن وأنزان لكل درس.

· ❌ لا تظهر الإجابات أثناء الاختبار.
· ✅ النتيجة في النهاية.

2.6 نظام الشارات

الشارة XP الحفظ الشرط
🥉 برونزية 0 ⏳ مؤقتة (شهر) إجابة ≤ 50% من المعياري
🥈 فضية 0 ⏳ مؤقتة (شهر) إجابة ≤ 40% من المعياري
🥇 ذهبية +100 XP ✅ للأبد إجابة ≤ 30% من المعياري

الشرط الأساسي: 5 إجابات متتالية بنفس الجلسة (في P أو Anzan).

في الاختبار (X): 7 إجابات بنفس الاختبار → 🥇 ذهبية.

الترقية عند المزيج: مثال: 3 × 🥉 + 2 × 🥈 في الجلسة → 🥇 ذهبية.

الطرد (Hierarchy): الشارة الأعلى تطرد الأدنى — داخل نفس الدرس (S).

XP:

· 🥇 ذهبية → +100 XP
· 🥈 و 🥉 → 0 XP
· قاعدة: XP يُحتسب مرة واحدة فقط لكل S.

العنصر يُفتح بعد

💎 5. بنك الأسئلة SRB (البنك الوحيد المستقبلي)

5.1 نظام ID الموحّد النهائي

```
SRB-{مستوى}-{مهارة}-{فقرة}-{عنصر}

├── مستوى: L0..L7
├── مهارة: S01..S20
├── فقرة: E (شاهد) | T (جرّب) | X (اختبار)
└── عنصر: 001..999
```

أمثلة:

```
SRB-L0-S01-E-001    ← شاهد
SRB-L0-S01-T-001    ← جرّب
SRB-L0-S01-X-001    ← اختبار

SRB-INTRO-P-001     ← صفحة مقدمة نظرية
```

5.2 بنية سؤال SRB

```json
{
  "id": "SRB-L0-S01-B001",
  "original_bank_id": null,
  "original_bank_section": "NEW-GAPFILL",
  "curriculum_level": "L0",
  "curriculum_section": "01",
  "curriculum_section_name": "تمثيل الأرقام 0-9",
  "stage": "basic",
  "in_curriculum": true,
  "classification_note": "شرح مختصر لمصدر السؤال",
  "question": "مثّل العدد 0 على المعداد",
  "result": "0",
  "solution": "لا نحرك أي خرزة...",
  "note": null,
  "time_text": null,
  "target_time_ms": [1500, 2500],
  "digit_count_max": 1,
  "operand_count": 1,
  "difficulty_score": 1.35,
  "mastery_threshold": 0.85,
  "prerequisite_id": null,
  "next_if_success": "SRB-L0-S01-B002",
  "next_if_fail": "SRB-L0-S01-B001"
}
```

📏 القواعد الصارمة

1. digit_count_max = عدد خانات الناتج (result) — لا المضروب.
2. operand_count = عدد الأرقام في السؤال (وليس في الجواب).
3. difficulty_score يتصاعد بانتظام (بلا قفزات عشوائية).
4. solution نظيف — بلا مسودات ولا "تصحيح:" ولا "لكن الأبسط".
5. next_if_fail يرجع 3 خطوات داخل القسم نفسه (في معظم الحالات).
6. mastery_threshold = 0.85 للأساسي · 0.8 للمتقدم.
7. stage = basic (L0–L3) · advanced (L4–L7).
8. target_time_ms = [min, max] حيث max = min × 1.5.

🔍 نقاط المراجعة السبع (لكل مستوى جديد)

1. صحة البيانات — لا يوجد digit_count_max خاطئ.
2. تسلسل الـ ID — B001 ← B002 بلا فراغات.
3. الشجرة — prerequisite / next_if_success / next_if_fail.
4. الرياضيات — الجواب والشرح صحيحان.
5. التغطية — كل قسم لا يقل عن 15 سؤالاً.
6. التوافق — الحقول المطلوبة للمحركات موجودة.
7. السلامة النصية — لا مسودات، ولا "تصحيح:".
