## 📐 قواعد العشرية

```

1. صحيح (result % 1 === 0)  → يُعرض كما هو
2. عشري (3.8)                → يُعرض 3.80
3. الإدخال بلا فاصلة (380)  → يُدخَل 380
4. الأعمدة: صحيح = خانات الناتج · عشري = صحيح + 2
5. المقارنة: Math.round(result × 100)
6. القسمة: بدون باقٍ فقط

```

✅ مطبقة في: CE1 · CE2 · PT · Practice · Anzan · Audio.
