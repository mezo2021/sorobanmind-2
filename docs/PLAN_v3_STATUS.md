## 🛠️ تفاصيل الحلول والخطوات المنجزة

### الخطوة 1 — Lockfile
- **الغرض:** ضمان استقرار الاعتمادات ومنع اختلاف نسخ الحزم.
- **التنفيذ:** إنشاء `p1-lockfile.yml` لتوليد `package-lock.json` عبر `npm install --package-lock-only`.

### الخطوة 2 — ضغط الصور
- **الغرض:** تقليص حجم الصور الكبيرة لتحميل أسرع.
- **التنفيذ:** استخدام أداة `pngquant` عبر `p2-images.yml` لضغط الصور فوق 60KB بجودة عالية.

### الخطوة 3 — Lazy للشاشات
- **الغرض:** تقليل حجم ملف JS الأساسي عند بدء التطبيق.
- **التنفيذ:** استيراد الشاشات بطريقة ديناميكية (Dynamic Imports) مع استثناء المكونات الدائمة مثل `Header`.
