## 2. الدروس المستفادة من الجلسات (Lessons Learned)

هذه الدروس مستخلصة من أخطاء حقيقية حدثت أثناء التطوير، وهي دستور لأي مطور يعمل على المشروع:

| # | الدرس المستفاد | الحل الحالي |
| :--- | :--- | :--- |
| **L1** | **TTS حساس جداً:** محرك الصوت يقرأ `-` كـ "إلى" و `←` كـ "سهم متجه". | دالة `Normalizer` تحول الرموز لكلمات (زائد، ناقص). |
| **L2** ".replace(/اكر/g, 'أَكَارْ')` في `speakCustom`. |
| **L3** | **`TopBar` لا يجب تعريفه داخل المكون:** يعيد React بناءه مع كل حرف الآلة الكاتبة → وميض أسود. | استدعاؤه كدالة `{TopBar()}` وحذف `backdrop-blur`. |
| **L4** | **الآلة الكاتبة تحتاج `ref`:** عند الضغط للتخطي، المؤقت القديم يستمر ويعيد كتابة النص. | دالة `skipTyping` تستخدم `typingRef` لإيقاف المؤقت. |
| **L5** | **`vh` كارثي على الجوال:** الشخصيات تختفي جانبيّاً إذا كبرت أكثر من اللازم. | استخدام `w-24` / `h-[vh]` مع `shrink-0` و`min-h-0`. |
| **L6** | **`backdrop-blur` يُتعب GPU:** في شاشة الأمثلة والتحدي، يجب تجنبه لتجنب الوميض. | استخدام خلفية صلبة `bg-slate-950`. |
| **L7** | **الأشباح ضرورية:** لوحة الصدارة الفارغة محبطة. | `GHOST_RECORDS` داخل `leaderboard.ts` + منع حفظها في المتصفح. |
| **L8** | **حفظ أفضل نتيجة (لا الأخيرة):** لتشجيع المحاولات. | `addRecord` تُحدّث السجل فقط إذا كانت النتيجة أفضل. |
| **L9** | **`recordMentalExam` v14:** يحفظ فقط `mode === 'exam'`. | قائمة بيضاء صارمة. |
| **L10** | **`isPreviewMode()` يجب أن يُحترم:** أي ميزة تحفظ بيانات يجب أن تُعطَّل في المعاينة. | `if (!isPreviewMode())` قبل كل حفظ. |
| **L11** | **إعادة اللعب (Rematch):** الخروج للقائمة يقطع متعة التحدي الأونلاين. | استخدام `key={matchId}` في React لتصفير الحالة **دون** مغادرة قناة Supabase. |

## 3. الميزات المؤجلة (Future Roadmap)

### 🥇 الأولوية الأولى: نظام XP للعبة (Gamification)

**المشكلة الحالية:** الطفل لا يكسب XP من بوابة الثقب الدودي، فلا يستطيع فتح الألعاب الأخرى.

**الحل المقترح:**
| الإجراء | XP المكتسب |
| :--- | :--- |
| إكمال مستوى قصصي | 20 XP |
| كل إجابة صحيحة في التحدي | 2 XP |
| اجتياز امتحان (400+) | 50 XP |
| الحصول على شهادة | 100 XP |
| الحصول على كيو أعلى | 200 XP (مكافأة) |

**الملفات التي ستُعدَّل:**
- `MentalArchivesManager.tsx`: إضافة `addXP` في `handleComplete`.
- `MentalArchivesExamRunner.tsx`: إضافة `addXP` في `handleSubmit`.

---

### 🥈 الأولوية الثانية: تحسينات بصرية إضافية

1. **تأثير الجزيئات على الخرزات** (عندما تُضاف لعبة سوروبان تفاعلية حقيقية).
2. **صفحة إعدادات المطور** داخل التطبيق (بدلاً من تعديل `localStorage` يدوياً).
3. **إشعار "شهادة جديدة"** عند الحصول على شهادة (Popup أو Toast).

## 5. القواعد الذهبية المتبقية (Golden Rules)

لأي مطور سيكمل المشروع، هذه هي القواعد غير القابلة للكسر:

1. **ممنوع** استخدام "يمين" أو "يسار" في نصوص الخطوات.
2. **ممنوع** كتابة الرموز الرياضية في `textAr` بصيغة (ناقص، يساوي)؛ استخدم `-` و `=`.
3. **يجب** تشكيل النصوص العربية بالكامل (TTS-Safe).
4. **يجب** استخدام `isPreviewMode()` عند إضافة أي ميزة تحفظ بيانات.
5. **يجب** تغليف الأرقام بـ `<Num>`.
6. **يجب** أن يكون `TopBar` مُستدعىً كدالة `{TopBar()}` وليس `<TopBar />`.
7. **يجب** استخدام `typingRef` في أي آلة كاتبة جديدة.
8. **ممنوع** تعديل `progressStore` أو `recordMentalExam` بدون مراجعة.
9. **ممنوع** تعديل أي رقم في `data/` أو `exams/` (البيانات موثقة رياضياً).
10. **يجب** الحفاظ على إعدادات الأونلاين المخصصة (5 أسئلة، 20 ثانية، 5000ms).
11. **ممنوع** الخروج من قناة Supabase عند "إعادة اللعب" (استخدم `matchId`).
