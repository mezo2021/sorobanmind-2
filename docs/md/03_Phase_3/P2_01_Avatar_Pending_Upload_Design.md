# P2-01 — تسجيل انتظار مزامنة الشخصية

> **الحالة:** ✅ مغلق تصميمياً
> **النطاق:** ملفان — `src/screens/ProfileScreen.tsx` + `src/lib/cloudSync.ts` (retryPendingAvatar فقط)
> **الاختبارات:** C100–C109

---

## 1. الوضع الحالي

### س: كيف يُحفظ Avatar حالياً في ProfileScreen؟
**ج:** في `handleSave()`:
1. يُحفظ `soroban_hero_key` محلياً.
2. يُحفظ اسم البطل محلياً.
3. إذا كان الوضع Cloud، تُستدعى `cloudSync.setMyAvatar()`.
4. **إذا فشلت، تظهر رسالة فشل، لكن لا تُكتب علامة انتظار الرفع.**

**الخلل:** فشل المزامنة لا يُسجّل في `soroban_avatar_pending_upload`.

### س: أين تُكتب هذه العلامة حالياً؟
**ج:** في مسارات أخرى:
- `AppGate.handleHeroSave` — عند اختيار البطل.
- `RoleSelection.handleAvatarSaved` — بعد فشل `setMyAvatar`.

### س: كيف تعمل `retryPendingAvatar`؟
**ج:**
- تقرأ العلامة (تتطلب `'1'`).
- تتحقق من `getMode() === 'cloud'`.
- تقرأ `soroban_hero_key` **الحالي**.
- ترفع الشخصية عبر RPC مباشرة (`set_my_avatar`).
- تحذف العلامة عند النجاح فقط.

**ملاحظة:** لا تعتمد على `setMyAvatar` العامة، بل تستدعي RPC مباشرة.

---

## 2. القرارات المعتمدة

| # | القرار | السبب |
|---|---|---|
| D1 | العلامة `'1'` = "مزامنة معلّقة لأحدث شخصية"، لا طابور تاريخي | الشخصية الحالية هي الهوية النشطة |
| D2 | كتابة العلامة **قبل** بدء الرفع | ضمان قابلية الاستئناف لو أُغلق التطبيق |
| D3 | بعد نجاح الرفع، مقارنة `soroban_hero_key` الحالي مع ما تم رفعه قبل حذف العلامة | منع فقدان علامة اختيار أحدث (سباق) |
| D4 | `isSaving` + `useRef` كقفل محلي لمنع النقر المزدوج | حماية متزامنة، لا Web Locks (لأنه محلي) |
| D5 | لا كتابة العلامة في Local mode | العلامة سحابية فقط |

---

## 3. حالات الفشل

| الحالة | السلوك |
|---|---|
| فشل `setMyAvatar` (RPC error) | العلامة تبقى |
| فشل شبكة | العلامة تبقى |
| إغلاق التطبيق بعد العلامة قبل الرفع | العلامة تبقى (تُستأنف) |
| تغيّر `soroban_hero_key` أثناء رفع قديم | نتيجة الرفع القديم **لا تحذف** العلامة |
| فقدان `soroban_hero_key` قبل إعادة المحاولة | لا رفع، العلامة تبقى |
| فشل كتابة العلامة في `localStorage` | لا ادعاء بضمان الإعادة |

## 4. الاختبارات

| # | السيناريو | النتيجة المطلوبة |
|---|---|---|
| C100 | Cloud + نجاح رفع | إزالة العلامة |
| C101 | فشل RPC | بقاء العلامة |
| C102 | فشل شبكة أو استثناء | بقاء العلامة |
| C103 | إغلاق التطبيق قبل اكتمال الرفع | العلامة تبقى |
| C104 | إعادة المحاولة مع جلسة صالحة | رفع الشخصية الحالية |
| C105 | فشل إعادة المحاولة | العلامة تبقى |
| C106 | Local mode | لا كتابة العلامة |
| C107 | غياب `hero_key` عند الإعادة | لا رفع، العلامة تبقى |
| C108 | فشل كتابة العلامة | إظهار فشل الحفظ |
| C109 | رفع A + اختيار B قبل اكتمال A | العلامة الخاصة بـ B لا تُحذف |
