# 🌐 خطوات التطوير المستقبلية (بعد اكتمال الاصلاح والمنهاج)

هذه الخطوات تُنفذ **بعد** الانتهاء من المهام (1) إلى (5) أعلاه، وبعد التأكد من أن التطبيق يعمل بشكل مستقر (CI أخضر، واختبارات Smoke ناجحة).

## المرحلة (أ): تحويل التطبيق إلى PWA (Progressive Web App)

### 🎯 الهدف
جعل التطبيق يعمل **بدون إنترنت** بشكل كامل، ويُثبَّت على الشاشة الرئيسية للهاتف (أيقونة)، ويعمل في وضع ملء الشاشة (بدون شريط عنوان المتصفح).

### 📋 المتطلبات التقنية
1.  **`vite-plugin-pwa`**: إضافة الحزمة إلى `devDependencies`.
2.  **`vite.config.ts`**: إعدادات Service Worker (التخزين المؤقت للملفات).
3.  **`public/manifest.json`**: ملف تعريف التطبيق (الاسم، الأيقونات، الألوان).
4.  **`index.html`**: ربط المانيفست.

### ⚙️ خطوات التنفيذ (عملياً)

**الخطوة 1: تثبيت الحزمة**
```bash
npm install -D vite-plugin-pwa
```

الخطوة 2: تحديث vite.config.ts

```typescript
import { VitePWA } from 'vite-plugin-pwa';

export default defineConfig({
  plugins: [
    react(),
    VitePWA({
      registerType: 'autoUpdate',
      includeAssets: ['favicon.ico', 'apple-touch-icon.png', 'masked-icon.svg'],
      manifest: {
        name: 'SorobanMind',
        short_name: 'Soroban',
        description: 'تعليم السوروبان الياباني',
        theme_color: '#0c0c0e',
        background_color: '#0c0c0e',
        display: 'standalone',
        icons: [
          { src: 'pwa-192x192.png', sizes: '192x192', type: 'image/png' },
          { src: 'pwa-512x512.png', sizes: '512x512', type: 'image/png' },
        ],
      },
      workbox: {
        globPatterns: ['**/*.{js,css,html,ico,png,svg,woff2}'],
        maximumFileSizeToCacheInBytes: 5 * 1024 * 1024,
      },
    }),
  ],
  // ... باقي الإعدادات
});
```

الخطوة 3: إنشاء public/manifest.json

```json
{
  "name": "SorobanMind",
  "short_name": "Soroban",
  "description": "تعليم السوروبان الياباني",
  "theme_color": "#0c0c0e",
  "background_color": "#0c0c0e",
  "display": "standalone",
  "orientation": "portrait",
  "start_url": "/",
  "icons": [
    { "src": "/pwa-192x192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "/pwa-512x512.png", "sizes": "512x512", "type": "image/png" }
  ]
}
```

الخطوة 4: إضافة الأيقونات

· إنشاء أيقونات pwa-192x192.png و pwa-512x512.png ووضعها في public/.

الخطوة 5: التفعيل

· بعد البناء (npm run build)، سيقوم vite-plugin-pwa تلقائياً بإنشاء Service Worker وملف manifest.json.

✅ النتيجة

· بدون إنترنت: التطبيق يفتح ويعمل (بعد أول زيارة).
· التثبيت: يظهر زر "إضافة إلى الشاشة الرئيسية" في المتصفح.
· التحديث: يتم تلقائياً في الخلفية.

🛡️ ملاحظة أمنية

· getSession (الذي سنضيفه في مهمة 5) سيعمل بشكل مثالي مع PWA، لأن ملفات التطبيق ستكون مخزنة محلياً، وسيتمكن المستخدم من فتح التطبيق والتحقق من الجلسة دون الحاجة للشبكة.

المرحلة (ب) [اختيارية]: تغليف التطبيق (Capacitor) للنشر على المتاجر

🎯 الهدف

تحويل تطبيق الويب (PWA) إلى تطبيق أصلي (APK / AAB) يمكن رفعه على Google Play أو المتاجر البديلة (Amazon Appstore، Huawei AppGallery).

⚠️ القيود السورية (مهم جداً)

· Google Play Console: لا يزال مقيداً للمطورين السوريين.
· الإعفاء الجديد: يسمح فقط بالتوزيع المحلي (APK sideloading) وليس بالنشر الدولي عبر Google Play.
· الحل العملي: توزيع APK مباشرة عبر موقعك أو متاجر بديلة (Amazon، Huawei)، أو التعاون مع شريك خارج سوريا لفتح حساب Google Play.

📋 المتطلبات التقنية

1. @capacitor/core و @capacitor/cli: الحزم الأساسية.
2. Android Studio (لبناء APK) أو Xcode (لـ iOS).
3. حساب مطور (25$ لـ Google Play، أو حساب مجاني لـ Amazon/Huawei).

⚙️ خطوات التنفيذ (عملياً)

الخطوة 1: تثبيت Capacitor

```bash
npm install @capacitor/core @capacitor/cli
npx cap init
```

· سيُطلب منك: اسم التطبيق (SorobanMind)، ومعرّف الحزمة (com.mezo2021.sorobanmind).

الخطوة 2: إضافة منصة Android

```bash
npx cap add android
```

· سيتم إنشاء مجلد android/ تلقائياً.

الخطوة 3: نسخ الملفات المبنية

```bash
npm run build
npx cap copy
```

الخطوة 4: فتح Android Studio

```bash
npx cap open android
```

· سيُفتح Android Studio، ومنه يمكنك بناء APK أو AAB.

الخطوة 5: بناء APK / AAB

· من Android Studio: Build > Build Bundle(s) / APK(s) > Build APK(s).
· أو من سطر الأوامر: ./gradlew assembleRelease (داخل مجلد android/).

✅ النتيجة

· ملف APK: يمكن توزيعه مباشرة (sideloading) أو رفعه على متاجر بديلة.
· ملف AAB: يمكن رفعه على Google Play (إذا توفر حساب مطور).

🛡️ ملاحظة أمنية

· التطبيق سيستخدم نفس كود React (بدون تغيير).
· getSession و PWA سيعملان داخل التطبيق الأصلي أيضاً.
· Supabase: المزامنة السحابية ستعمل كما هي (الإنترنت مطلوب للمزامنة فقط).

📌 ملاحظات ختامية

· الأولوية القصوى: إكمال المحتوى (L5-L7) أولاً، لأن PWA والتغليف لن يضيفا قيمة بدون محتوى مكتمل.
· PWA هو الحل الأمثل لسوريا: لأنه يتجاوز قيود متاجر التطبيقات، ويعمل على أي متصفح، ويوفر تجربة قريبة من التطبيق الأصلي.
· Capacitor هو بوابة المتاجر: يُستخدم فقط بعد اكتمال PWA، ويعتمد على نفس الكود.
· الوضع السوري: لا تنتظر رفع الحظر عن Google Play Console قريباً. ابدأ بـ PWA و APK المباشر.
