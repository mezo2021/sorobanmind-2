## 🎯 الترتيب التنفيذي المعتمد

### 🟢 5. مؤشر الاتصال (Connection Indicator) — *البداية*
- **الهدف:** إظهار حالة الاتصال (أخضر/أحمر) في شاشة `AuthModal`.
- **الملفات المستهدفة:** `src/components/AuthModal.tsx`.
- **المتطلبات:**
  - استخدام `navigator.onLine`.
  - إضافة مستمعين `online` / `offline`.
  - نصوص ثنائية اللغة (عربي/إنجليزي).
- **الحالة:** ⬜ لم يبدأ.

### 🟠 4. ترجمة الألعاب (Games Translation)
- **الهدف:** دمج الترجمات (ar/en) للألعاب الخمسة.
- **الملفات المستهدفة:** `src/components/games/*`.
- **ملاحظة:** قيد التنفيذ حالياً بمساعدة Claude.
- **الحالة:** ⏳ قيد التنفيذ.

### 🔴 1. استكمال المنهاج (L5 - L6 - L7)
- **الهدف:** كتابة الدروس المتبقية وترجمتها وإضافة TTS لها.
- **الملفات المستهدفة:**
  - `src/curriculum/lessons/L5/S11.ts` و `S12.ts`
  - `src/curriculum/lessons/L6/S13.ts` و `S14.ts`
  - `src/curriculum/lessons/L7/S15.ts`
  - `src/curriculum/lessons/index.ts`
- **المتطلبات:**
  - اتباع بروتوكول `id: "L{level}-S{num}"`.
  - إضافة `storyAudioText` و `miniStory`.
  - الترجمة الكاملة (ar/en).
- **الحالة:** ⬜ لم يبدأ.

### 🟠 2. الحفظ التلقائي (Auto-Save)
- **الهدف:** مزامنة تلقائية مع Supabase بعد كل تغيير (بـ Debounce 3s).
- **الملفات المستهدفة:** `src/store/progressStore.ts` و `src/lib/cloudSync.ts`.
- **المتطلبات:**
  - إضافة مستمع `subscribe` في المتجر.
  - استدعاء `cloudSync.saveToCloud()` تلقائياً.
- **الحالة:** ⬜ لم يبدأ.

### 🟡 3. ربط المحرك (Engine Integration) — *يحتاج دراسة المنهاج*
- **الهدف:** استبدال Stubs في `adaptiveEngine` و `problemGenerator` بالربط الفعلي مع `srb-adapter`.
- **الملفات المستهدفة:** `src/engine/adaptiveEngine.ts` و `src/engine/problemGenerator.ts`.
- **شرط البدء:** **يجب دراسة المنهاج كاملاً (L0-L7) قبل البدء**، لأن المحرك يعتمد على البيانات الكاملة لتوليد الأسئلة التكيفية.
- **الحالة:** ⬜ لم يبدأ (بانتظار اكتمال المنهاج).

- **آلية العمل:** عند إضافة دروس L5-L7، ستُفتح الشارات الجديدة تلقائياً (مثل "خبير الجذور" و"خبير العشريات")، لأن `progressStore` هو المصدر الوحيد للحقيقة.

لكن في README.md مكتوب حرفياً:

النتيجة: هذا الوعد غير حقيقي حالياً. التطبيق لن يفتح بدون إنترنت، لأن المتصفح لا يخزن ملفات HTML/JS/CSS محلياً. تعديل getSession لن يحل المشكلة وحده.

---

التناقض الثاني: الخصوصية تغيّرت جذرياً ⚠️

من README.md:

🔒 Complete Privacy | All data stored strictly on the user's local device
✅ Data stored 100% locally on device
✅ Zero server transmissions

لكن أنت الآن أضفت @supabase/supabase-js (موجود في package.json)، وأصبح هناك إرسال بيانات للسيرفر. هذا يناقض الوعد القديم.

النتيجة: يجب تحديث README.md ليعكس الواقع الجديد (بيانات محلية + مزامنة سحابية آمنة عبر RLS).

🎯 ماذا يعني هذا للتنفيذ؟
