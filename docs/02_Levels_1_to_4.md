## 🏛️ المستوى الأول: رفوف الذاكرة — إبلا وماري (الكيو 10 و 9)
*   **الهدف التاريخي:** إصلاح روابط ألواح الطين في أقدم أرشيفات بلاد الشام.
*   **المهارة الرياضية:** جمع بسيط (3 صفوف من خانة واحدة)، دون تجاوز العشرة (10 كيو)، ثم تجاوز العشرة بقاعدة الصديق الصغير (9 كيو).
*   **سرعة التحدي:** 14.4 ثانية للسؤال.

### 1. المثال المحلول (قاعدة السوروبان)
**الحالة 1 (جمع مباشر - 10 كيو):** `2 + 3 + 1 = 6`
*   **الخطوة 1:** نمثل الرقم **2** (نرفع خرزتين سفليتين).
*   **الخطوة 2:** نضيف **3** (نرفع ثلاث خرزات سفلية). المجموع 5 (الخرزة العلوية).
*   **الخطوة 3:** نضيف **1** (نرفع خرزة سفلية). النتيجة: **6**.

**الحالة 2 (قاعدة الصديق الصغير - 9 كيو):** `1 + 2 + 4 = 7`
*   **الخطوة 1:** نمثل 1، ثم نضيف 2 (المجموع 3).
*   **الخطوة 2:** نضيف **4**. لا توجد خرزات سفلية كافية، فنستخدم قاعدة الصديق الصغير: `+4` تعني `(+5 - 1)`.
*   **الخطوة 3:** ننزل الخرزة العلوية (+5)، ونبعد خرزة سفلية واحدة (-1). النتيجة: **7**.

*   **الخطوة 3:** نضيف **1** ليصبح 13.
*   **الخطوة 4:** نضيف **2** ليصبح **15**.

**الحالة 2 (5 صفوف - 7 كيو):** `7 + 5 + 8 + 3 + 6 = 29`
*   **الخطوة 1:** 7 + 5 = 12.
*   **الخطوة 2:** +8 (قاعدة `+10 - 2`): العشرات 2، الآحاد (2-2=0). الناتج 20.
*   **الخطوة 3:** +3 = 23.
*   **الخطوة 4:** +6 (قاعدة `+10 - 4`). النتيجة: **29**.

🛠️ دليل المطور: كيف تضيف مستوى جديداً؟ (Developer Guide)

لإضافة أي مستوى جديد (مثلاً المستوى الخامس)، اتبع هذه الخطوات الصارمة:

الخطوة 1: إنشاء ملف البيانات (Data File)

· اذهب إلى مجلد src/components/games/MentalArchivesGame/data/.
· أنشئ ملفاً جديداً باسم level5Data.ts.
· اكتب فيه البيانات متبعاً "العقد البرمجي" (LevelData من gameTypes.ts). تأكد من وجود story، example، و questions.

الخطوة 2: تحديث المدير (The Manager)

· افتح ملف MentalArchivesManager.tsx.
· أضف سطر الاستيراد في الأعلى:
  ```typescript
  import { LEVEL_5_DATA } from './data/level5Data';
  ```
· ابحث عن الدالة getLevelData وأضف الحالة الجديدة:
  ```typescript
  const getLevelData = () => {
    switch (currentLevel) {
      case 0: return INTRO_DATA;
      case 1: return LEVEL_1_DATA;
      case 2: return LEVEL_2_DATA;
      case 3: return LEVEL_3_DATA;
      case 4: return LEVEL_4_DATA;
      case 5: return LEVEL_5_DATA; // 👈 السطر الجديد
      default: return INTRO_DATA;
    }
  };
  ```
· ابحث عن دالة handleComplete وحدث شرط التوقف:
  ```typescript
  if (nextLevel > 5) { // 👈 غير الرقم ليطابق أعلى مستوى
    onBack();
    return;
  }
  ```

الخطوة 3: الأصول (Assets) - اختياري

· إذا كان المستوى يحتاج صوراً جديدة، ضعها في المجلد الرئيسي واستوردها داخل الملف levelXData.ts أو مرر مسارها إذا كانت ديناميكية. المحرك الحالي يعتمد على الصور الأساسية، لذا ستحتاج لتعديل بسيط في المحرك إذا أردت صوراً مخصصة لكل مستوى.

الخطوة 4: الاختبار

· قم بعمل Commit. افتح اللعبة، وعبر المستويات حتى تصل للمستوى الجديد. تأكد من أن الأسئلة والقصص تعمل دون أخطاء برمجية.
