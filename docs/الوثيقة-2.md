🎯 الجزء 1: ملخص تنفيذي (اقرأ أولاً)

ما نحن عليه:

· تطبيق React + Supabase يعمل، لكنه نصف معدّل (تسجيل جديد لا يعمل بالكامل).
· 1 حساب تجريبي فقط، لا مستخدمين حقيقيين.
· المطور يعمل على جوال Android فقط (GitHub Web Editor + Supabase Web).

الهدف النهائي:

· لا اسم طفل حقيقي في أي مكان (لا محلي، لا سحابي، لا JSON، لا user_metadata).
· 3 أوضاع: زائر (بلا حفظ) + محلي (بلا حساب) + سحابي (بحساب).
· اسم البطل (heroName) بديل محلي، من قائمة مغلقة.
· Avatar + Sequential Number للسحابي فقط.
· JSON آمن (قائمة بيضاء، بلا token).
· PIN محلي لحماية تقارير ولي الأمر.
· V2 functions لتجنب DROP FUNCTION.

ما أوصى به كلاود (نعتمده):

1. تقليل 3 مسارات إلى 2 (+ زائر).
2. محلي بلا حساب (PIN بدل حساب Supabase).
3. V2 functions (get_hall_of_fame_v2).
4. JSON قائمة بيضاء (لا blacklist).
5. show_on_leaderboard default = FALSE.
6. BIGSERIAL للرقم التسلسلي (مع UNIQUE).
7. ترتيب: React أولاً، ثم SQL، ثم واجهات.

```sql
CREATE OR REPLACE FUNCTION public.handle_new_profile()
RETURNS TRIGGER
LANGUAGE plpgsql SECURITY DEFINER SET search_path = public AS $$
DECLARE
  v_avatar TEXT;
  v_consent BOOLEAN;
BEGIN
  BEGIN
    v_avatar := COALESCE(NEW.raw_user_meta_data ->> 'avatar_id', 'rabbit_fast');
    v_consent := COALESCE((NEW.raw_user_meta_data ->> 'consent_leaderboard')::boolean, FALSE);
    
    INSERT INTO public.public_profiles (user_id, avatar_id, show_on_leaderboard)
    VALUES (NEW.id, v_avatar, v_consent)
    ON CONFLICT (user_id) DO NOTHING;
  EXCEPTION WHEN OTHERS THEN
    RAISE WARNING 'handle_new_profile failed for %: %', NEW.id, SQLERRM;
  END;
  RETURN NEW;
END;
$$;
```

3. إنشاء get_hall_of_fame_v2:

```sql
CREATE OR REPLACE FUNCTION public.get_hall_of_fame_v2(
  p_game_id TEXT,
  p_period TEXT DEFAULT 'all',
  p_limit INT DEFAULT 10
) RETURNS TABLE (
  pos INT, avatar_id TEXT, sequential_number BIGINT,
  score INT, time_ms INT, is_me BOOLEAN
)
LANGUAGE sql SECURITY DEFINER SET search_path = public STABLE AS $$
  SELECT
    (row_number() OVER (ORDER BY s.score DESC, s.time_ms ASC NULLS LAST, s.updated_at ASC))::INT,
    p.avatar_id, p.sequential_number, s.score, s.time_ms, (s.user_id = auth.uid())
  FROM public.scores s
  JOIN public.public_profiles p ON p.user_id = s.user_id AND p.show_on_leaderboard
  WHERE s.game_id = p_game_id
    AND s.period_key = CASE WHEN p_period = 'month' 
        THEN to_char(timezone('UTC', now()), 'YYYY-MM') ELSE 'all' END
  ORDER BY s.score DESC, s.time_ms ASC NULLS LAST, s.updated_at ASC
  LIMIT LEAST(GREATEST(p_limit, 1), 50);
$$;
```

4. إنشاء get_my_rank_details_v2:

```sql
CREATE OR REPLACE FUNCTION public.get_my_rank_details_v2(
  p_game_id TEXT,
  p_period TEXT DEFAULT 'all'
) RETURNS TABLE (
  game_id TEXT, period_key TEXT, player_rank BIGINT,
  avatar_id TEXT, sequential_number BIGINT,
  score INT, time_ms INT
)
LANGUAGE sql SECURITY DEFINER SET search_path = public STABLE AS $$
  WITH ranked AS (
    SELECT
      s.user_id, s.game_id, s.period_key, s.score, s.time_ms, s.updated_at,
      p.avatar_id, p.sequential_number,
      ROW_NUMBER() OVER (
        ORDER BY s.score DESC, s.time_ms ASC NULLS LAST, s.updated_at ASC
      ) AS player_rank
    FROM public.scores s
    JOIN public.public_profiles p ON p.user_id = s.user_id AND p.show_on_leaderboard
    WHERE s.game_id = p_game_id
      AND s.period_key = CASE WHEN p_period = 'month' 
          THEN to_char(timezone('UTC', now()), 'YYYY-MM') ELSE 'all' END
  )
  SELECT r.game_id, r.period_key, r.player_rank, r.avatar_id, r.sequential_number, r.score, r.time_ms
  FROM ranked r
  WHERE r.user_id = auth.uid()
  LIMIT 1;
$$;
```

5. استبدال submit_score (فحص الموافقة):

```sql
CREATE OR REPLACE FUNCTION public.submit_score(
  p_game_id TEXT, p_score INT, p_time_ms INT DEFAULT NULL
) RETURNS VOID LANGUAGE plpgsql SECURITY DEFINER SET search_path = public AS $$
DECLARE
  v_uid UUID := auth.uid();
  v_max INT;
  v_visible BOOLEAN;
  v_month TEXT := to_char(timezone('UTC', now()), 'YYYY-MM');
  v_key TEXT;
BEGIN
  IF v_uid IS NULL THEN RAISE EXCEPTION 'Not authenticated'; END IF;

  SELECT show_on_leaderboard INTO v_visible
  FROM public_profiles WHERE user_id = v_uid;

  IF COALESCE(v_visible, FALSE) = FALSE THEN
    RETURN;  -- بصمت، لا حفظ بدون موافقة
  END IF;

  SELECT max_score INTO v_max FROM score_games WHERE game_id = p_game_id;
  IF v_max IS NULL OR p_score < 0 OR p_score > v_max THEN
    RAISE EXCEPTION 'Invalid score';
  END IF;

  FOREACH v_key IN ARRAY ARRAY['all', v_month] LOOP
    INSERT INTO scores (user_id, game_id, period_key, score, time_ms)
    VALUES (v_uid, p_game_id, v_key, p_score, p_time_ms)
    ON CONFLICT (user_id, game_id, period_key) DO UPDATE
      SET score = EXCLUDED.score, time_ms = EXCLUDED.time_ms, updated_at = NOW()
      WHERE EXCLUDED.score > scores.score
         OR (EXCLUDED.score = scores.score 
             AND COALESCE(EXCLUDED.time_ms, 2147483647) < COALESCE(scores.time_ms, 2147483647));
  END LOOP;
END;
$$;
```
