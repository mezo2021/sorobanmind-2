## 1. الرؤية العامة لقسم الامتحانات
بعد إنهاء الطفل للمستويات القصصية، يُفتح "قسم الامتحانات". هذا القسم ليس جزءاً من القصة، بل هو اختبار جاد (Exam Mode).
*   **لا يوجد تلميحات:** لا سوروبانا ولا جود يتدخلان (إلا في وضع التدريب الاختياري للتحقق من الجاهزية).
*   **إدخال رقمي فقط:** محاكاة للأنزان الذهني الخالص.
*   **تقييم نهائي:** تُجمع العلامات وتظهر النتيجة النهائية بعد انتهاء الوقت أو تسليم الورقة.
*   **منفصل عن الأونلاين:** نتائج التحديات الأونلاين لا تؤثر إطلاقاً على تقدم الامتحانات أو لوحة الصدارة.

## 3. الهيكل التقني للامتحانات (TypeScript Schema)
العقد البرمجي الفعلي المعتمد في ملف `data/exams/examTypes.ts`:

```typescript
export type ExamQuestionType = 'mitori' | 'multiplication' | 'division';

export interface ExamQuestion {
  id: string;
  type: ExamQuestionType;
  numbers: number[];
  answer: number;
  hasSubtraction?: boolean; // 🆕 تستخدم في امتحان 1 كيو للطرح
}

export interface ExamSection {
  titleAr: string;
  titleEn: string;
  questions: ExamQuestion[];
  pointsPerQuestion: number;
}

export interface GradeThreshold {
  score: number;
  grade: string;
}

export interface KyuExamData {
  id: string;
  levelNameAr: string;
  levelNameEn: string;
  timeLimitSeconds: number;
  totalQuestions: number;
  totalMarks: number;
  passingScore: number;
  sections: ExamSection[];
  gradeThresholds?: GradeThreshold[];
  requires: string[];
  requiresExam?: string;
}
```

4. خصائص محاكي الامتحان (MentalArchivesExamRunner.tsx)

تم تطوير المحرك ليتضمن ميزات صارمة تضمن العدالة:

1. الخلط العشوائي (Shuffle): يتم خلط الأسئلة داخل كل قسم عشوائياً عند بدء كل محاولة، لمنع حفظ ترتيب الإجابات.
2. حساب الدرجات الديناميكي: يُحسب الناتج بناءً على وزن السؤال (10 للميتوري، 5 للضرب والقسمة).
3. وضع التدريب (Training) مقابل الامتحان (Exam):
   · في التدريب: لا يوجد مؤقت، ويظهر للطفل مستوى جاهزيته.
   · في الامتحان: بمؤقت (720 ثانية)، النجاح (400/500) يفتح الامتحان التالي. يتم حفظ النتيجة في المتجر المركزي progressStore (v14) فقط إذا كان mode === 'exam'.
4. التعامل مع الطرح (السالبة): محرك العرض الذكي يخفي علامة + إذا كان الرقم التالي سالباً (ليظهر كطرح -).
5. استقرار المؤقت: يتم إدارة المؤقت عبر useEffect مستقل خارج تحديثات الحالة (لحل مشكلة Race Conditions).
6. نظام الشهادات: عند تجاوز امتحان بنجاح (400+)، يتم فتح ExamCertificateModal.tsx لتوليد شهادة PDF/PNG قابلة للطباعة (مقاس A4).

5. تفاصيل الامتحانات (بنك الأسئلة الحقيقي)

أ. امتحان 10-7 كيو (الورقة المشتركة)

· الأسئلة: 50 سؤالاً (ميتوري فقط).
· الوقت: 720 ثانية.
· التقييم: 10 نقاط لكل سؤال (المجموع 500).
· العتبات: 250 (10كيو) | 300 (9كيو) | 350 (8كيو) | 400 (7كيو - النجاح).

ب. امتحانات 6 كيو إلى 1 كيو

· الأسئلة: 80 سؤالاً (20 ميتوري + 30 ضرب + 30 قسمة).
· الوقت: 720 ثانية (12 دقيقة).
· النجاح: 400 نقطة من 500.
· التدرج:
  · exam_6 (6 كيو): ميتوري (5 صفوف مختلطة) | ضرب (2×1) | قسمة (3÷1).
  · exam_5 (5 كيو): ميتوري (8 خانات) | ضرب (2×1) | قسمة (3÷1).
  · exam_4 (4 كيو): ميتوري (5×2 خانات) | ضرب (2×1) | قسمة (3÷1).
  · exam_3 (3 كيو): ميتوري (5×3 خانات) | ضرب (3×1) | قسمة (3÷1) (بمعالجة الأصفار).
  · exam_2 (2 كيو): ميتوري (7×3 خانات) | ضرب (2×2) | قسمة (4÷2) و (3÷2).
  · exam_1 (1 كيو): ميتوري (10 صفوف مع طرح) | ضرب (3×2) | قسمة (4÷2 و 4÷3).

6. واجهة المستخدم (UI) لشاشة الامتحان

مطابقة لملف MentalArchivesExamRunner.tsx:

1. الشريط العلوي: زر إنهاء (يفتح مودال تأكيد)، مؤقت تنازلي، عداد الإجابات.
2. شبكة الأسئلة (Grid): تُعرض الأسئلة كبطاقات (تركيز السؤال النشط، إظهار الإجابة المدخلة).
3. لوحة المفاتيح (RelicKeypad): ثابتة في الأسفل.
4. شاشة النتيجة: تعرض الدرجة، وحالة النجاح/الرسوب، وزر "مراجعة الإجابات" (الذي يفتح صفحة قابلة للطباعة).
5. الشهادة: زر "استلام الشهادة" يظهر عند النجاح.

7. دليل المطور: إضافة تعديل على الامتحانات

1. إضافة ملف امتحان جديد:
   · أنشئ ملفاً في data/exams/ (مثل examX.ts).
   · استخدم واجهة KyuExamData. تأكد من إضافة hasSubtraction: true إذا كان الامتحان يحتوي على طرح في الميتوري.
2. تفعيل الامتحان في الواجهة:
   · في MentalArchivesExams.tsx، أضف الامتحان إلى مصفوفة EXAMS وغيّر isReady: true.
   · أضف شرط التشغيل في الأسفل: if (isRunning && selectedExamId === 'exam_X').
3. دعم وضع المعاينة:
   · النظام مبرمج تلقائياً لفتح جميع الامتحانات في وضع المعاينة (عبر isPreviewMode())، مع تعطيل الحفظ.
4. قواعد صارمة:
   · ممنوع تعديل أرقام الأسئلة في ملفات examX.ts (البيانات موثقة رياضياً).
   · ممنوع المساس بـ progressStore.ts أو ربطه بنتائج الأونلاين.
